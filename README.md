# Token Creation – Cryptonino (CTN)

Cryptonino (CTN) is a cryptocurrency created as a learning and experimentation project focused on understanding how blockchain technology works in real environments.

The project explores key concepts such as transaction validation, basic security principles, and token economics, covering the full lifecycle from token creation to deployment.

Rather than aiming to be a commercial product, Cryptonino is designed to strengthen practical knowledge of smart contracts, testing approaches, and on-chain behavior through hands-on development and experimentation.
